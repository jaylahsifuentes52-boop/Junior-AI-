JUNIOR AI HUB — COLORFUL WEBSITE

Files:
- index.html: Junior AI home, Get help, and Fix my code pages
- style.css: colorful responsive styling
- app.js: chat demo, help form, code-fixer UI and copy button

PREVIEW:
1. Extract this ZIP.
2. Open index.html in a browser.

FIX MY CODE:
Click the Fix my code card on the home screen, choose a language, paste your code, optionally paste an error, then press Fix my code. The current version demonstrates the form and returns a suggested draft. It does NOT perform reliable AI-powered repair yet. For real code correction, connect a secure server/backend to an AI model; do not put private API keys in public JavaScript.

GET HELP:
Click Get help in the sidebar or top bar. The form prepares a support message but does not automatically send it to a support team.

PUBLISH:
Upload index.html, style.css, and app.js together to your static hosting service.
